# 🏥 MediPortal

MediPortal is a web-based application developed as part of the **Web Engineering course**.  
The project follows a **full-stack architecture** using modern web technologies.

---

## 🚀 Tech Stack

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MySQL
- Sequelize (ORM)

### Tools
- Git & GitHub
- VS Code
- npm
